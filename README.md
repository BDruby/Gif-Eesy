# ⚡ 灵动图 (GifPulse / Gif-Eesy)

> 新一代前卫时尚的视频转 GIF 动图与 GIF 极速二次压缩 Web 应用。  
> 100% 纯前端浏览器本地离线处理，保障私密影像零泄露，轻量丝滑，手机触控极致友好。

项目开源仓库：[https://github.com/BDruby/Gif-Eesy.git](https://github.com/BDruby/Gif-Eesy.git)

---

## ✨ 核心功能亮点

### 🎬 1. 视频转 GIF (Video to GIF)
- **多格式支持**：兼容 MP4、WebM、MOV、MKV 等主流浏览器支持的视频格式。
- **双向指针时间轴剪辑 (Trimmer)**：毫秒级精准微调截取范围，支持选区循环播放与当前播放头指针跟随。
- **自由与真实比例裁剪 (Crop)**：
  - 支持 **1:1（方形头像/微信表情）**、**9:16（竖屏短视频）**、**16:9（宽屏）**、**4:3** 与自由拖拽选框。
  - 严格以实际视频画面边界为基准计算比例与坐标，彻底消除画面黑边畸变。
- **实时尺寸映射 (Dynamic Dimensions)**：
  - 选择任意裁剪比例时，导出尺寸（280p / 400p / 540p / 720p）均精确计算对应宽高像素并实时同步展示。
- **帧率与回放特效**：
  - 帧率自由调控（6 ~ 24 FPS）。
  - 支持 **0.5x ~ 2.0x 调速**。
  - 支持 **魔法倒放 (Reverse)** 与 **鬼搐往返 (Boomerang)** 循环特效。
- **表情包图层与贴合水印 (Meme & Watermark)**：
  - 经典 Meme 表情包大字（顶部大字 + 底部大字，粗体白字黑描边）。
  - 自定义水印签名，严格贴合**图片自身边界**（左上角、右上角、左下角、右下角、居中），无论裁剪还是全景均完美贴图，绝不溢出到外部黑边。

### 🗜️ 2. GIF 极速二次压缩 (GIF Optimizer)
- **智能抽帧策略**：支持保留全部帧、隔帧抽帧（帧数减半且保持自然回放速度）、抽 2 留 1（超轻量）。
- **重采样量化调色板**：32色、64色、128色、256色自由选择。
- **无损/有损尺寸缩放**：25% ~ 100% 无级缩放。
- **体积缩减对比**：实时显示压缩前后文件体积与节省百分比（如 `-75%`）。

### 🎯 3. 一键场景预设 (Smart Presets)
- 💬 **微信表情包神器**：自动压制在 **< 1MB**，满足微信个人表情添加标准。
- 🌟 **微信大表情**：**< 5MB** 高清规格，画质细腻无噪点。
- 👾 **Discord / Slack Emoji**：128px 方形裁切，体积严格控制在 **< 256KB**。
- 💎 **高清全彩动图**：540p / 20 FPS / 256 全色彩输出。

### 🛡️ 4. 极致隐私与前沿架构 (100% Client-side)
- **零服务器算力 & 隐私安全**：所有媒体处理均在浏览器客户端内通过 Web Worker 异步多线程执行，视频和动图绝不上传任何第三方服务器。
- **跨设备支持**：PC 宽屏两栏工作台与手机端单栏+底部吸底操作栏自适应切换。
- **一键分享与复制**：支持保存下载、一键复制动图到剪贴板，以及手机原生 Web Share 系统分享。

# 3. 在浏览器中打开
http://127.0.0.1:5173/

## 🐧 Linux 服务器一键交互式部署

本项目内置了交互式部署脚本 `deploy.sh`，可一键完成本地打包、远程 SSH 连接、静态文件同步以及 Nginx / Docker 自动配置：

```bash
# 运行一键交互式部署脚本
./deploy.sh
```

脚本将引导您输入：
1. 服务器 IP / 域名
2. SSH 端口与登录用户名
3. 部署模式：
   - **[1] Nginx 自动配置**（推荐，自动生成静态站点配置并重载 Nginx，自带 Gzip 压缩与静态文件强缓存）
   - **[2] Docker / Docker-Compose 容器化运行**（自动构建轻量 Alpine Nginx 容器）
   - **[3] 仅同步文件**（仅传输构建文件到指定目录）

## 🐳 Docker 独立运行

如果希望在任何支持 Docker 的服务器上快速运行：

```bash
# 1. 本地构建产物
npm run build

# 2. 启动容器
docker compose up -d --build
```
即可在服务器的 `http://localhost:80` 端口直接访问。
